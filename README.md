# Fashion Heaven — Fashion Storefront & Admin

Fashion Heaven is a personal full-stack web project for browsing fashion products and managing store operations through an admin dashboard.

## Features

- Browse and filter the product catalog.
- Use customer authentication, a shopping cart, and checkout.
- Manage products and inventory from the admin dashboard.
- Review revenue reports in the admin area.

## Technology

- **Frontend:** React
- **Backend:** Node.js, Express
- **Database:** Microsoft SQL Server

## Project Work

I built the customer-facing storefront and the admin dashboard, including the shopping and inventory-management workflows.
